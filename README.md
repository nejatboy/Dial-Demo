# Dial · Demo playlist

A small M3U playlist to try the Dial player, published with GitHub Pages:

https://nejatboy.github.io/Dial-Demo/dial.m3u

Live channels (16) are generated test patterns with an XMLTV guide; movies are 2-minute excerpts of Blender open movies
(CC BY, credits on https://nejatboy.github.io/Dial-Demo/). Nothing here is real broadcast content.

Generated by `tools/demo_playlist.py` in the Dial project; don't edit by hand.
